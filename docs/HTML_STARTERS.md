# Own editable motion starters

Four sources provide distinct starting directions: a kinetic editorial title, a layered landscape, an artistic oscillator array and staggered elastic letters. They are written here, with inline Canvas/CSS/JavaScript, no external assets or runtime, and `window.seek(t)` calculated directly from time. The oscillator scene is an artistic phase study, not a physics or astronomy result.

`html_motion_starters` / `GET /api/html-motion/starters` lists bilingual names, descriptions and source format. `html_motion_starter_create` / `POST /api/html-motion/starters` creates an ordinary, separate HTML composition: profile, literal text, optional name, width, height, fps, duration and project_id. Omitting dimensions/timing uses1280×720/30fps/4s. Existing validation and project identity checks apply. There is no predefined reference-app document format or compatibility requirement.

Use the existing workshop's composition selector to open the result, edit its full HTML, save revisions or restore them. `html_motion_get` reads source in ordinary pages; frame/storyboard return actual PNGs; render exports H.264. Text is JSON-escaped literal Canvas content; a closing script tag supplied as text cannot become executable markup. Creating another starter leaves earlier compositions intact. The scene's palette and typography belong to the content, not the application's theme. The output has no audio; ordinary timeline audio remains available.

Research origin: the supplied100HTML gallery suggested parallax, oscillators and elastic typography, while the course's starter code illustrates closed-form motion and time-based keyframes. Only concepts and mathematical techniques informed these sources. No gallery code, character assets or original starter code was copied. This code and API belong to Lumiere and evolve independently.
